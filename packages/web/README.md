# @polinom-io/px-ds-react

React components and design tokens of the Polinom.io Design System, for the web. Built to be used from Astro: every component renders on the server, and each one can be its own island.

> **Status: in build (0.x), not published yet.** No component is `Stable`. See each component's README for what is not built yet.

## Install

The package is published to GitHub Packages. Add the registry for the scope to your project's `.npmrc`:

```ini
@polinom-io:registry=https://npm.pkg.github.com
```

GitHub Packages needs a token to install, even for public packages. Put it in your own `~/.npmrc`, not the project's (pnpm 12 ignores credentials in a project `.npmrc`):

```ini
//npm.pkg.github.com/:_authToken=<a GitHub token with read:packages>
```

Then `pnpm add @polinom-io/px-ds-react` (React 18.3 or 19 is a peer dependency).

## Use in Astro

Load the tokens and styles once, in the layout, and set the brand on `<html>`:

```astro
---
// src/layouts/Base.astro
import '@polinom-io/px-ds-react/tokens.css';
import '@polinom-io/px-ds-react/styles.css';
---
<html lang="en" data-theme="px">
  <body><slot /></body>
</html>
```

`data-theme` is `px` (Polinom.io) or `treatmint`. Leave `data-mode` off to follow the visitor's system setting; set `data-mode="light"` or `"dark"` only for a choice the visitor made. For one section in another theme or mode, set both `data-theme` and `data-mode` on that element.

Components with no behaviour need no client JavaScript. Interactive ones say which directive they expect:

```astro
---
import { Card, Tabs } from '@polinom-io/px-ds-react';
---
<Card tone="secondary" title="Strategy">The highest-degree term.</Card>
<Tabs client:visible label="Engagement" tabs={[{ label: 'Overview', content: 'What we do' }, { label: 'Process', content: 'How we work' }]} />
```

Props passed from an `.astro` file must be serializable (strings, numbers, arrays, plain objects). Callbacks such as `onClick` or `onClose` only work inside a React component that is itself an island.

To load only some styles, import `tokens.css`, then `@polinom-io/px-ds-react/<Name>.css` per component instead of `styles.css`. Base styles (focus ring, icon button, reduced motion) are in `styles.css` only.

## Develop

```sh
pnpm install
pnpm --filter @polinom-io/px-ds-react typecheck
pnpm --filter @polinom-io/px-ds-react test     # server render, hydration, axe-core, behaviour, stylesheet checks
pnpm --filter @polinom-io/px-ds-react build    # dist/: ESM + types, styles, tokens.css, fonts
```

`src/tokens/tokens.css` is generated by `node tools/build.mjs` at the repo root; never edit it by hand. Components use tokens only: no raw colours, no theme-specific values, no React context (each island is its own React root), no browser APIs during render, and ids from `useId`. The tests fail if any of those break.
